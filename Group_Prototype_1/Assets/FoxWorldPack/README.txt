FoxWorldPack
============
Contains 12 Unity prefabs, created automatically on import via the Editor builder.
If needed: Tools > Fox World Pack > Generate or Rebuild All Prefabs.
Prefabs: Nature_RoundTree, Nature_PineTree, Nature_SmallRock,
Nature_MediumRock, Nature_LargeRock, Nature_TreeStump,
SciFi_MetalBlock, SciFi_GlowBlock, SciFi_PushCrate,
SciFi_TechPillar, SciFi_AutoDoor, SciFi_EnergyBarrier.
This is procedural low-poly geometry. All roots have a collider;
SciFi_PushCrate also has a Rigidbody. Does not edit your scene.
