Fox Decoration Pack
===================

Includes:
- RoundTree prefab
- PineTree prefab
- PinkFlower prefab
- YellowFlower prefab
- DaisyClump prefab

How to use:
1. Copy the Assets/FoxDecorationPack folder into your Unity project Assets folder.
2. Let Unity compile.
3. In Unity menu, run: Tools -> Fox Decoration Pack -> Create or Rebuild Prefabs
4. Prefabs will appear under Assets/FoxDecorationPack/Prefabs/
5. Drag them into your scene.

Notes:
- These are decorative props with colliders, mainly for visual dressing.
- They do not affect score, health, or gameplay.
- Generated using primitive meshes, so no external FBX is required.
